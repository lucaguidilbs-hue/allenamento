# Allenamento

App web personale per l'allenamento: palestra, casa e trasferte, con animazioni degli esercizi, registrazione di carichi e ripetizioni, cicli di 6–8 settimane e resoconto da condividere con Claude.

I dati restano salvati sul telefono (localStorage). Per il backup usa la sezione **Esercizi → Copia backup**.

Pubblicata con GitHub Pages.
